# Thari

Thari is an offline-first personal finance application built with React, TypeScript, Vite, and Capacitor.

## Run locally

**Prerequisites:** Node.js.

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Create a web build: `npm run build`
4. Build and sync Android assets: `npm run build:android`

Core finance, budgets, goals, wallets, reports, debts, and recurring operations work locally without an AI provider or API key.
